# Primary sources

Reviewed 2026-11-16. These links establish research alignment, not current eligibility or an open application window.

- [DARPA SynQuaNon program](https://www.darpa.mil/research/programs/synthetic-quantum-nanostructures): superconducting metamaterials, bottom-up design, application areas, Defense Sciences Office and program manager.
- [DARPA: Embarking on Quest for New Quantum Materials, August 9, 2023](https://www.darpa.mil/news/2023/new-quantum-material): reduced cooling overhead, functional devices, distinction between theory/modeling in the Disruption Opportunity and experimental testing in the full program.
- [SAM.gov award notice HR001123S0050-HR001124C0442](https://sam.gov/opp/ea583ae1c6014d81a26b7220eaf4e85f/view): historical May 2024 award to HRL Laboratories; not an open solicitation.
- [DARPA Disruptioneering](https://www.darpa.mil/research/opportunities/disruptioneering): program framework. Listing a program does not establish that its submissions are open.

The toy model is an implementation illustration. This source list does not claim that DARPA endorses its assumptions or that it predicts material/device behavior.
