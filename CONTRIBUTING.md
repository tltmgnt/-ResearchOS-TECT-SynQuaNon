# Contributing

Keep changes focused and run `python -m unittest discover -s tests -v`. For models, document equations, units, domain, limitations, reference checks, and uncertainty. Keep synthetic examples clearly labeled. Preserve raw evidence and do not change checksums to conceal failed integrity checks. Do not commit credentials or unpublished partner data. Use reviewed public or authorized data in this public repository.

Submit changes through a pull request with a behavior summary and validation results. Do not claim a scientific improvement solely from software tests or the toy model.
